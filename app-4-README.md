# App 4 — DataDocs

Archive: [`app-4.zip`](app-4.zip)

DataDocs is a Java Swing text editor with selectable system fonts, font sizes, styled controls, and document-saving features.

## Requirements

- Java Development Kit
- Graphical desktop session

## Build and run

```bash
unzip app-4.zip
javac -d build 4/DataDocs.java
java -cp build DataDocs
```
