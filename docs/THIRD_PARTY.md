# Third-Party Dependencies

- ScrapZone uses Raylib-cs 8.0.0 and its transitive native Raylib components; see the package's upstream license.
- Trestrio development uses Electron and electron-builder; their dependency license notices are restored through npm and included by the release builder where applicable.
- Java applications use the standard JDK/Swing libraries and do not vendor external Java libraries.

Dependency trees are restored from lock/project files and are not archived as company source.
