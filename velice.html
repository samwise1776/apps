HOW TO USE THIS GUIDE

Read in order or jump directly to what you need.

Every example is copyable. Code is highlighted locally without an external library. Mark chapters complete as you go; progress stays in this browser. The guide distinguishes implemented version 0.1 behavior from reserved future features.

Chapter 01

Install and run Velice

Start from source, install the command, run a file, evaluate an expression, or enter the REPL.

Requirements

Velice needs CPython 3.10 or newer. The interpreter itself has no third-party runtime dependencies. Tk is used only when a GUI opens.

  • Linux, macOS, or Windows
  • Python 3.10+
  • Optional: VS Code for the bundled editor extension

Install locally

unzip velice.zip
cd velice
python3 -m unittest discover -s tests
python3 -m pip install -e .
velice version

Four ways to run

# Run a source file
velice run examples/hello_world.velice

# Run without installing
python3 -m velice run examples/hello_world.velice

# Evaluate and print one expression
velice eval "1 + 2 * 3"

# Start the interactive REPL
velice repl
Expected first output: Hello, World!
Chapter 02

Source files, blocks, and comments

Velice files use the .velice extension and UTF-8 text.

Identifiers can contain letters, digits, and underscores, but cannot begin with a digit. Braces are the recommended way to make blocks explicit. Indentation is also understood; a tab counts as four spaces.

# A line comment
let language_name = "Velice"

/* A block comment can
   continue across lines. */
if language_name == "Velice" {
    print("Clear blocks")
}
Style: use four spaces, descriptive snake_case names, braces for multi-line blocks, and one statement per line.
Chapter 03

Values, literals, and types

The runtime is dynamic. Optional type annotations are stored but are not statically enforced in version 0.1.

Core values

TypeExample
int42, 0xff, 1_000
float3.14, 2.5e-3
string"hello", r"raw"
bool / niltrue, false, nil
array / map[1, 2], {"a": 1}

Inspect values

let name: string = "Velice"
let release = 0.1
let ready = true
let missing = nil

print("Hello ${name}!")
print(typeof(release)) # float
print(sizeof(name))    # 6

Strings support single quotes, double quotes, triple-quoted multi-line text, raw strings, escapes, and ${expression} interpolation.

Chapter 04

Variables, constants, and deferred code

Bindings are immutable unless you explicitly make them mutable.

let name = "Velice"       # immutable
let mut count = 0         # mutable
var score = 10            # shorthand for mutable
const MAX_USERS = 1000    # constant

count += 1
score = score + 5
print(name, count, score)

# A parenthesized var initializer becomes deferred code.
var answer = (6 * 7)
print(answer())           # 42

var greet = (print("hello later"))
greet()
Important: assigning to a plain let or a const produces a runtime error. Use let mut or var when reassignment is intentional.
Chapter 05

Operators and precedence

Velice includes familiar arithmetic, comparison, Boolean, range, pipe, and fallback operators.

print(2 + 3 * 4)             # 14
print(2 ** 8)                # 256
print("ab" * 3)              # ababab
print([1] + [2, 3])          # [1, 2, 3]
print(1..5)                  # inclusive range
print(6 & 3, 6 | 3, 6 ^ 3)   # 2 7 5 (bitwise)

let value = nil
print(value ?? "fallback")  # fallback

let age = 20
let label = age >= 18 ? "adult" : "minor"
print(label)

fn square(x) { return x * x }
print(5 |> square)

Low → high: |> · ?: · ?? · or · and · comparison · bitwise & | ^ · range · addition · multiplication · power · unary · calls/access.

Chapter 06

Conditions and loops

Use conditions as statements or expressions, then choose the loop that matches the job.

let temperature = 21

if temperature > 25 {
    print("warm")
} elif temperature > 10 {
    print("comfortable")
} else {
    print("cold")
}

let label = if temperature > 20 { "nice" } else { "cool" }

for i in 0..3 { print(i) }

let mut n = 0
while n < 3 {
    n += 1
}

loop {
    n += 1
    if n < 5 { continue }
    break
}

break and continue work inside for, while, and loop.

Chapter 07

Functions, defaults, recursion, and closures

Functions are values. They can be passed, returned, stored, and closed over surrounding state.

fn greet(name, greeting = "Hello") {
    return greeting + ", " + name + "!"
}

fn fib(n) {
    if n < 2 { return n }
    return fib(n - 1) + fib(n - 2)
}

fn counter() {
    let mut value = 0
    return fn() {
        value += 1
        return value
    }
}

let next = counter()
print(greet("Ray"))
print(fib(10))
print(next(), next(), next())

Mark a parameter var or mut if the function needs to reassign it. A bare return returns nil.

Chapter 08

Arrays, maps, indexing, and collection helpers

Arrays and maps are mutable reference values. Strings and numbers behave as values.

let numbers = [3, 1, 4]
append(numbers, 1)
push(numbers, 5)
print(numbers[0])
print(numbers[1:3])
print(sorted(numbers))
print(reversed(numbers))
print(sum(numbers))

let profile = {
    "name": "Velice",
    "version": "0.1.0"
}
print(profile["name"])
print(keys(profile))
print(values(profile))
print(items(profile))

Other helpers include len, range, pop, insert, remove, min, and max.

Chapter 09

Higher-order functions and pipelines

Transform data with lambdas and pass values through readable processing stages.

let numbers = [1, 2, 3, 4]
let doubled = map(numbers, fn(x) { return x * 2 })
let evens = filter(numbers, fn(x) { return x % 2 == 0 })
let total = reduce(numbers, fn(sum, x) { return sum + x })

fn square(x) { return x * x }
fn increment(x) { return x + 1 }
print(4 |> square |> increment) # 17

fn make_adder(amount) {
    return fn(value) { return value + amount }
}
let add_five = make_adder(5)
print(add_five(10))
Chapter 10

Pattern matching

match selects an arm by value or pattern and can return a value.

fn classify(value) {
    return match value {
        0 => "zero",
        1 => "one",
        n if n < 0 => "negative",
        n if n > 100 => "huge",
        _ => "normal",
    }
}

print(classify(0))
print(classify(42))

match [1, 2] {
    [a, b] => print(a + b),
    _ => print("another shape"),
}

Supported pattern forms include literals, identifiers that bind values, wildcard _, arrays, tuples, alternatives, and if guards.

Chapter 11

Classes, instances, and inheritance

init is the constructor. Instance fields can be created through self.

class Animal {
    fn init(name) {
        self.name = name
    }

    fn speak() {
        print(self.name + " makes a sound")
    }
}

class Dog extends Animal {
    fn speak() {
        print(self.name + " barks!")
    }
}

let dog = Dog("Rex")
dog.speak()

Velice version 0.1 uses single inheritance. Overridden methods resolve on the child class before searching its parent.

Chapter 12

Structs, traits, enums, and generic patterns

Velice parses and represents higher-level modeling constructs while keeping runtime behavior intentionally small.

trait Runnable {
    fn run()
}

struct Point {
    x: float
    y: float
}

enum Direction {
    North,
    East,
    South,
    West,
}

let origin = Point(0.0, 0.0)
print(origin.x, origin.y)

# Dynamic code usually uses generic-style functions.
fn identity(value) { return value }
fn make_pair(left, right) { return [left, right] }
Version 0.1 scope: structs construct data records. Trait and enum declarations are available, but full interface enforcement, rich enum values, and static generics are future work. Use higher-order functions for reusable generic behavior today.
Chapter 13

Errors, cleanup, assertions, and fallbacks

Catch runtime failures, throw your own values, and keep fallback logic compact.

fn divide(total, count) {
    if count == 0 { throw "count cannot be zero" }
    return total / count
}

try {
    print(divide(10, 0))
} catch error {
    print("caught:", error)
} finally {
    print("cleanup always runs")
}

assert(2 + 2 == 4, "math changed")
let setting = nil
print(setting ?? "default")

defer { print("leaving this block") }

panic(message) is available for unrecoverable failures. defer cleanup is best-effort in the current interpreter.

Chapter 14

Modules and imports

Split code into files and import a module, selected names, or every exported name.

math.velice

fn square(x) {
    return x * x
}

fn cube(x) {
    return x * x * x
}

main.velice

import "math.velice"
print(math.square(5))

from "math.velice" import cube
print(cube(3))

from "math.velice" import *

Imports execute the target in its own global environment. Namespaces are file-based in version 0.1; richer module namespaces are planned.

Chapter 16

Strings, interpolation, and text methods

Use built-in string methods for the most common parsing checks.

let language = "Velice"
print("Learning ${language}")
print(language.len)
print("hello".contains("ell"))
print("hello".starts("he"))
print("hello".ends("lo"))
print("foo(bar)baz".inbetween("()"))
print("print(\"Hello\")".inbetween("\"\""))

let path = r"C:\projects\velice"
print(path)

inbetween(delimiters) returns text between the first opening character and last closing character. It returns an empty string when the pair is not found.

Chapter 17

Read files and accept command-line arguments

argu exposes script arguments. readFileLines provides a stateful line reader.

# Run with: velice run scan.velice source.velice
let path = argu.0
print("argument count:", argu.len)

let lines = readFileLines(path)
print("line count:", lines.len)

while lines.hasMore() {
    let line = lines.currentLine()
    if line.contains("print(") {
        print("found:", line)
    }
}

lines.reset()
print("first:", lines.current())
print("cursor:", lines.position())

You can also index and iterate both values: argu[0], lines[0], for item in argu, and for line in lines. Missing files and out-of-range arguments produce runtime errors.

Chapter 18

Build your first native GUI

The GUI standard library uses Python’s built-in Tk toolkit and automatically records calls when no display is available.

import gui

let window = Window("My Velice App", 640, 420)
let message = Label("Ready")
let button = Button("Click me")

button.on_click {
    message.text = "Hello from Velice!"
}

window.add(message)
window.add(button)
gui.run()
python3 -m velice run app.velice

# Force headless recording mode for CI or servers
VELICE_GUI=none python3 -m velice run app.velice

import gui exposes both the gui module and constructors such as Window, Button, and Canvas.

Chapter 20

GUI events, dialogs, file pickers, and clipboard

Event handlers use trailing blocks. The event map carries pointer and keyboard details.

import gui

var window = Window("Events", 520, 420)
var input = TextField("", placeholder="Type here")
var save = Button("Save")

input.on_change {
    print("text:", input.text)
}

window.on_key_down {
    print("key:", event.key)
}

save.on_click {
    if gui.confirm("Save this text?") {
        let path = gui.save_file("Save")
        gui.clipboard.copy(input.text)
        gui.toast("Copied and ready to save", 2.0)
    }
}

window.add(input)
window.add(save)
gui.run()

Events: click, double-click, change, select, key down/up, mouse move/enter/leave/wheel, focus, blur, load, and close. Snake case and camelCase names both work.

Dialogs: alert, toast, confirm, input_box, open_file, save_file, choose_folder, choose_color, and choose_font.

Chapter 21

Canvas drawing, declarative UI, and themes

Draw directly or describe an interface with named widget blocks.

Canvas

import gui
var window = Window("Canvas", 640, 480)
var canvas = Canvas(600, 400, "#ffffff")

canvas.draw_rect(20, 20, 80, 80, "#e74c3c")
canvas.draw_oval(120, 20, 80, 80, "#2ecc71")
canvas.draw_line(20, 150, 580, 150, "#3498db", 3)
canvas.draw_text(300, 320, "Velice", "#34495e", 20, true)
window.add(canvas)
gui.run()

Declarative DSL

import gui
gui.set_theme("Midnight")

window Main {
    title = "Declarative App"
    Label title { text = "Welcome" }
    Button greet {
        text = "Greet"
        onClick { print("Hello!") }
    }
}

run Main

Built-in themes include Light, Dark, Midnight, Ocean, Forest, Solarized, Neon, Glass, Material, Fluent, macOS, Windows, and Linux. Runtime helpers are gui.run, gui.update, gui.set_theme, gui.window, and gui.quit.

Chapter 23

Packages, publishing, and VS Code

Manage local, cached, Git, and registry packages, then enable the bundled editor tools.

# Package commands inside a Velice project
velice install package-name@1.2.0
velice install ./local-package
velice install https://github.com/example/package.git
velice list
velice update
velice uninstall package-name
velice package
velice publish

# Discover the local cache
velice install-dir

Package builds use .vpkg, library descriptors use .vlib, and source packages may use .vsrc. Resolved versions are recorded in velice.lock. The default remote registry address is configurable with VELICE_REGISTRY.

VS Code extension

  1. Open editor/vscode in VS Code.
  2. Press F5 to launch the Extension Development Host, or package it with vsce package.
  3. Select “Velice Icons” as the file icon theme.
  4. Use “Velice: Run File” or “Velice: Open REPL”.

The extension includes syntax highlighting, bracket/comment rules, snippets, a file icon, run commands, and a headless-GUI setting.
