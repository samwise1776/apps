HOW TO USE THIS GUIDE

Read in order or jump directly to what you need.

Every example is copyable. Code is highlighted locally without an external library. Mark chapters complete as you go; progress stays in this browser. The guide distinguishes implemented version 0.1 behavior from reserved future features.

Chapter 01

Install and run Velice

Start from source, install the command, run a file, evaluate an expression, or enter the REPL.

Requirements

Velice needs CPython 3.10 or newer. The interpreter itself has no third-party runtime dependencies. Tk is used only when a GUI opens.

  • Linux, macOS, or Windows
  • Python 3.10+
  • Optional: VS Code for the bundled editor extension

Install locally

unzip velice.zip
cd velice
python3 -m unittest discover -s tests
python3 -m pip install -e .
velice version

Four ways to run

# Run a source file
velice run examples/hello_world.velice

# Run without installing
python3 -m velice run examples/hello_world.velice

# Evaluate and print one expression
velice eval "1 + 2 * 3"

# Start the interactive REPL
velice repl
Expected first output: Hello, World!
Chapter 02

Source files, blocks, and comments

Velice files use the .velice extension and UTF-8 text.

Identifiers can contain letters, digits, and underscores, but cannot begin with a digit. Braces are the recommended way to make blocks explicit. Indentation is also understood; a tab counts as four spaces.

# A line comment
let language_name = "Velice"

/* A block comment can
   continue across lines. */
if language_name == "Velice" {
    print("Clear blocks")
}
Style: use four spaces, descriptive snake_case names, braces for multi-line blocks, and one statement per line.
Chapter 03

Values, literals, and types

The runtime is dynamic. Optional type annotations are stored but are not statically enforced in version 0.1.

Core values

TypeExample

string / char"hello", 'x', r"raw"
bool / niltrue, false, nil
array / map[1, 2], {"a": 1}
tuple(1, "two") — runtime value; limited dedicated APIs

Inspect values

let name: string = "Velice"
let release = 0.1
let ready = true
let missing = nil

print("Hello ${name}!")
print(typeof(release)) # float
print(len(name))       # 6

Strings support single quotes, double quotes, triple-quoted multi-line text, raw strings, escapes, and ${expression} interpolation. sizeof is recognized by the parser but has no runtime implementation in version 0.1; use len for strings, arrays, maps, arguments, and file-line readers.

Chapter 04

Variables, constants, and deferred code

Bindings are immutable unless you explicitly make them mutable.

let name = "Velice"       # immutable
let mut count = 0         # mutable
var score = 10            # shorthand for mutable
const MAX_USERS = 1000    # constant

count += 1
score = score + 5
print(name, count, score)

# A parenthesized var initializer becomes deferred code.
var answer = (6 * 7)
print(answer())           # 42

var greet = (print("hello later"))
greet()
Important: assigning to a plain let or a const produces a runtime error. Use let mut or var when reassignment is intentional.

const is a runtime-immutable binding, not a compile-time substitution. A first bare assignment such as score = 10 also creates a mutable global in version 0.1, but explicit let/var declarations are clearer.

Chapter 05

Operators and precedence

Velice includes familiar arithmetic, comparison, Boolean, range, pipe, and fallback operators.

print(2 + 3 * 4)             # 14
print(2 ** 8)                # 256
print("ab" * 3)              # ababab
print([1] + [2, 3])          # [1, 2, 3]
print(1..5)                  # inclusive range
print(6 & 3, 6 | 3, 6 ^ 3)   # 2 7 5 (bitwise)

let value = nil
print(value ?? "fallback")  # fallback

let age = 20
let label = if age >= 18 { "adult" } else { "minor" }
print(label)

fn square(x) { return x * x }
print(5 |> square)

Low → high: |> · ?? · or · and · comparison · bitwise & | ^ · range · addition · multiplication · power · unary · calls/access.

Ternary status: although ? and : tokens and a ternary parser function exist, postfix parsing consumes ? first in version 0.1. Use the working if condition { value } else { value } expression form.

Division between two integers uses floor division; if either operand is a float, / returns a float. The a..b operator is inclusive, while the range(...) library function follows Python-style exclusive stop behavior.

Chapter 06

Conditions and loops

Use conditions as statements or expressions, then choose the loop that matches the job.

let temperature = 21

if temperature > 25 {
    print("warm")
} elif temperature > 10 {
    print("comfortable")
} else {
    print("cold")
}

let label = if temperature > 20 { "nice" } else { "cool" }

for i in 0..3 { print(i) }

let mut n = 0
while n < 3 {
    n += 1
}

loop {
    n += 1
    if n < 5 { continue }
    break
}

break and continue work inside for, while, and loop.

Chapter 07

Functions, defaults, recursion, and closures

Functions are values. They can be passed, returned, stored, and closed over surrounding state.

fn greet(name, greeting = "Hello") {
    return greeting + ", " + name + "!"
}

fn fib(n) {
    if n < 2 { return n }
    return fib(n - 1) + fib(n - 2)
}

fn counter() {
    let mut value = 0
    return fn() {
        value += 1
        return value
    }
}

let next = counter()
print(greet("Ray"))
print(fib(10))
print(next(), next(), next())

A bare return returns nil. The parser records var/mut parameter markers, but the version 0.1 runtime currently creates every parameter as mutable, so those markers do not yet enforce a difference.

Chapter 08

Arrays, maps, indexing, and collection helpers

Arrays and maps are mutable reference values. Strings and numbers behave as values.

let numbers = [3, 1, 4]
append(numbers, 1)
push(numbers, 5)
print(numbers[0])
print(numbers[1:3])
print(sorted(numbers))
print(reversed(numbers))
print(sum(numbers))

let profile = {"name": "Velice", "version": "0.1.0"}
print(profile["name"])
print(keys(profile))
print(values(profile))
print(items(profile))

Other helpers include len, range, pop, insert, remove, min, and max.

append(array, value) mutates and returns the array; push mutates and returns nil. pop(array) removes the final item, and insert/remove mutate in place.

Chapter 09

Higher-order functions and pipelines

Transform data with lambdas and pass values through readable processing stages.

let numbers = [1, 2, 3, 4]
let doubled = map(numbers, fn(x) { return x * 2 })
let evens = filter(numbers, fn(x) { return x % 2 == 0 })
let total = reduce(numbers, fn(sum, x) { return sum + x })

fn square(x) { return x * x }
fn increment(x) { return x + 1 }
print(4 |> square |> increment) # 17

fn make_adder(amount) {
    return fn(value) { return value + amount }
}
let add_five = make_adder(5)
print(add_five(10))
Chapter 10

Pattern matching

match selects an arm by value or pattern and can return a value.

fn classify(value) {
    return match value {
        0 => "zero",
        1 => "one",
        n if n < 0 => "negative",
        n if n > 100 => "huge",
        _ => "normal",
    }
}

print(classify(0))
print(classify(42))

match [1, 2] {
    [a, b] => print(a + b),
    _ => print("another shape"),
}

Supported pattern forms include literals, identifiers that bind values, wildcard _, fixed-length arrays, alternatives with |, and if guards. Tuple values exist, but tuple-pattern syntax is not implemented in version 0.1.

Chapter 11

Classes, instances, and inheritance

init is the constructor. Instance fields can be created through self.

class Animal {
    fn init(name) {
        self.name = name
    }

    fn speak() {
        print(self.name + " makes a sound")
    }
}

class Dog extends Animal {
    fn speak() {
        print(self.name + " barks!")
    }
}

let dog = Dog("Rex")
dog.speak()

Velice version 0.1 uses single inheritance. Overridden methods resolve on the child class before searching its parent.

Superclass access: inherited methods and constructors are found automatically, but the reserved super keyword cannot be used as an expression in version 0.1. A child constructor must assign the fields it needs directly.
Chapter 12

Structs, traits, enums, and generic patterns

Velice parses and represents higher-level modeling constructs while keeping runtime behavior intentionally small.

Supported: structsPartial: enumsParsed only: traits and implPlanned: static generics
trait Runnable {
    fn run()
}

struct Point {
    x: float
    y: float
}

enum Direction {
    North,
    East,
    South,
    West,
}

let origin = Point(0.0, 0.0)
print(origin.x, origin.y)

# Dynamic code usually uses generic-style functions.
fn identity(value) { return value }
fn make_pair(left, right) { return [left, right] }
Version 0.1 scope: structs construct field records and can contain methods. Enum declarations currently create metadata only; variants are not rich runtime values. Trait declarations parse but create no runtime contract, and impl blocks do not currently attach methods. Generic type parameters are not supported. Use ordinary dynamic functions and higher-order functions for reusable behavior today.
Chapter 13

Errors, cleanup, assertions, and fallbacks

Catch runtime failures, throw your own values, and keep fallback logic compact.

fn divide(total, count) {
    if count == 0 { throw "count cannot be zero" }
    return total / count
}

try {
    print(divide(10, 0))
} catch error {
    print("caught:", error)
} finally {
    print("cleanup always runs")
}

assert 2 + 2 == 4, "math changed"
let setting = nil
print(setting ?? "default")

fn work() {
    defer { print("leaving work") }
    print("working")
}
work()

defer runs queued blocks in reverse order when its enclosing block completes normally. catch handles Velice runtime errors raised as VeliceError; arbitrary host-Python exceptions are not converted consistently. The word panic is reserved, but panic(...) is not callable in version 0.1; use throw for an explicit runtime failure.

Chapter 14

Modules and imports

Split code into files and import a module namespace, selected top-level names, or every top-level name.

math.velice

fn square(x) {
    return x * x
}

fn cube(x) {
    return x * x * x
}

main.velice

import "math.velice"
print(math.square(5))

from "math.velice" import cube
print(cube(3))

from "math.velice" import *

use "math.velice" as formulas
print(formulas.square(6))

Imports execute and cache the target in a separate environment. use follows the same parser/runtime path as import. There is no export declaration in version 0.1: selected and wildcard imports expose the module’s top-level environment. Relative file imports resolve from the running source file; project/package lookup also searches src/, packages/, and the local package cache.

Chapter 16

Strings, interpolation, and text methods

Use built-in string methods for the most common parsing checks.

let language = "Velice"
print("Learning ${language}")
print(language.len)
print("hello".contains("ell"))
print("hello".starts("he"))
print("hello".ends("lo"))
print("foo(bar)baz".inbetween("()"))
print("print(\"Hello\")".inbetween("\"\""))

let path = r"C:\projects\velice"
print(path)

inbetween(delimiters) returns text between the first opening character and last closing character. It returns an empty string when the pair is not found.

Chapter 17

Read files and accept command-line arguments

argu exposes script arguments. readFileLines provides a stateful line reader.

# Run with: velice run scan.velice source.velice
let path = argu.0
print("argument count:", argu.len)

let lines = readFileLines(path)
print("line count:", lines.len)

while lines.hasMore() {
    let line = lines.currentLine()
    if line.contains("print(") {
        print("found:", line)
    }
}

lines.reset()
print("first:", lines.current())
print("cursor:", lines.position())

You can also index and iterate both values: argu[0], lines[0], for item in argu, and for line in lines. Missing files and out-of-range arguments produce runtime errors.

Chapter 18

Build your first native GUI

The GUI standard library uses Python’s built-in Tk toolkit and automatically records calls when no display is available.

import gui

var window = Window("My Velice App", 640, 420)
var message = Label("Ready")
var button = Button("Click me")

button.on_click {
    message.text = "Hello from Velice!"
}

window.on_close {
    gui.quit()
}

window.add(message)
window.add(button)
gui.run()
python3 -m velice run app.velice

# Force headless recording mode for CI or servers
VELICE_GUI=none python3 -m velice run app.velice

import gui exposes both the gui module and constructors such as Window, Button, and Canvas. The native X button fires on_close but does not destroy anything automatically. In a single-window app, call gui.quit() as shown so the hidden Tk root and event loop also close. In a multi-window app, window.close() destroys only that window; quit after the final window closes.

Core constructor properties such as text, value, items, ranges, and Canvas dimensions work for their matching widgets. After a widget is added, common Tk properties including text, enabled, visible, width, height, background, font_size, and tooltip are applied where the native control accepts them.

Partial property layer: placeholder, readonly, max_length, and generic bold/color setters are stored but are not wired to all native widgets in version 0.1. TextField reads also do not yet synchronize typed Tk text back into field.text. Menu and tab classes exist, but their full parent/child realization path is incomplete.

window.closable(false) replaces the native close request with a no-op. It does not remove or gray out the title-bar X. With the default true, clicking X fires on_close; call window.close() when other windows should remain, or gui.quit() to end the whole GUI application.

Chapter 20

GUI events, dialogs, file pickers, and clipboard

Event handlers use trailing blocks. Native mouse and keyboard events provide pointer and key details.

import gui

var window = Window("Events", 520, 420)
var enabled = Checkbox("Enable saving", value=true)
var save = Button("Save")

enabled.on_change {
    print("enabled:", enabled.value)
}

window.on_key_down {
    print("key:", event.key)
}

window.on_close {
    gui.quit()
}

save.on_click {
    if gui.confirm("Prepare a save path?") {
        let path = gui.save_file("Save")
        gui.clipboard.copy(path)
        gui.toast("Path copied", 2.0)
    }
}

window.add(enabled)
window.add(save)
gui.run()

Events: click, double-click, select, key down/up, mouse move/enter/leave/wheel, focus, blur, load, and close are connected by the native backend. on_change is connected for checkbox/toggle and slider controls; TextField change notification is not wired in version 0.1. Snake case such as on_key_down and camelCase such as onKeyDown normalize to the same handler.

The event map contains x, y, key, and state for Tk mouse/keyboard events. Command-style events such as button clicks, changes, load, and close may receive an empty map.

Dialogs: alert, toast, confirm, input_box, open_file, save_file, choose_folder, choose_color, and choose_font. File/folder/color pickers return an empty value when cancelled. choose_font currently returns the first available Tk font family rather than opening a full font chooser.

Chapter 21

Canvas drawing, declarative UI, and themes

Draw directly or describe an interface with named widget blocks.

Canvas Supported

import gui
var window = Window("Canvas", 640, 480)
var canvas = Canvas(600, 400, "#ffffff")

canvas.draw_rect(20, 20, 80, 80, "#e74c3c")
canvas.draw_oval(120, 20, 80, 80, "#2ecc71")
canvas.draw_line(20, 150, 580, 150, "#3498db", 3)
canvas.draw_text(300, 320, "Velice", "#34495e", 20, true)
window.on_close { gui.quit() }
window.add(canvas)
gui.run()

Declarative DSL Partial

import gui
gui.set_theme("Midnight")

window Main {
    title = "Declarative App"
    Label title { text = "Welcome" }
    Button greet {
        text = "Greet"
        onClick { print("Hello!") }
    }
}

Main.on_close { gui.quit() }
gui.run()

Canvas supports rectangles, filled rectangles, ovals, lines, polygons, text, arcs, clearing, and PostScript snapshots through screenshot("drawing.ps"). Drawing calls made before window.add(canvas) are queued and replayed when the Canvas attaches to its visible window.

Built-in themes include Light, Dark, Midnight, Ocean, Forest, Solarized, Neon, Glass, Material, Fluent, macOS, Windows, and Linux. Theme application covers the common Tk widgets; ttk controls and some specialized controls have partial styling. Runtime helpers are gui.run, gui.update, gui.set_theme, gui.window, and gui.quit.

DSL runtime detail: run Main calls show() for a registered DSL window but does not start Tk’s event loop. An interactive DSL program still needs gui.run(). Window-level event blocks and event-payload injection inside DSL handlers are incomplete, so bind Main.on_close imperatively as shown.

Create projects and use the toolchain

The CLI can scaffold a standard project, validate source, build descriptors, run tests, lint, format, and generate documentation.

velice new my-app
cd my-app

velice run
velice build
velice build --release
velice debug
velice test
velice lint

velice docs
velice clean

Project layout

my-app/
├── velice.toml
├── src/main.velice
├── packages/
├── tests/
├── docs/
├── assets/
├── build/
├── README.md
├── LICENSE
└── CHANGELOG.md

velice.toml

name = "my-app"
version = "0.1.0"
description = "A Velice application"
license = "MIT"
language = "1.0"
entry = "src/main.velice"

dependencies = []
Tool behavior in 0.1: build parses source and writes descriptive .vlib files; it does not emit executable bytecode or a native binary. debug runs that debug build. test executes every tests/*.velice file, lint checks tokenization/tabs/trailing whitespace, format normalizes whitespace, and docs writes a Markdown file containing project source. Native compilation is planned.
Chapter 23

Packages, publishing, and VS Code

Manage local, cached, and Git packages; use the registry client when a compatible service is configured; then enable the bundled editor tools.

Supported: local, Git, cache, .vpkgPartial: remote registry and publishReserved: .vsrc workflow
# Package commands inside a Velice project
velice install package-name@1.2.0
velice install ./local-package
velice install https://github.com/example/package.git
velice search package-name
velice list
velice update
velice uninstall package-name
velice package
velice publish

# Discover the local cache
velice install-dir

velice package creates a ZIP-based .vpkg; builds create descriptive .vlib files. The .vsrc extension is defined in code but has no create/install workflow yet. Dependency resolution uses the local cache and writes resolved versions to velice.lock.

Registry and publishing status: the client defaults to https://packages.velice.org or VELICE_REGISTRY, but this repository does not provide or prove a live public registry service. Remote search falls back to the offline cache when unreachable. velice publish currently validates, tests, builds, packages, hashes, and prints the intended registry URL—it does not upload the package.

VS Code extension

  1. Open editor/vscode in VS Code.
  2. Press F5 to launch the Extension Development Host, or package it with vsce package.
  3. Select “Velice Icons” as the file icon theme.
  4. Use “Velice: Run File” or “Velice: Open REPL”.

The extension includes TextMate syntax highlighting, bracket/comment/indent rules, snippets, a file icon theme, Run File and Open REPL commands, and a headless-GUI setting. It does not implement autocomplete, semantic diagnostics, debugging, or an LSP.
