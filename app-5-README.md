# App 5 — Datapro Analytics

Archive: [`app-5.zip`](app-5.zip)

Datapro is a Java Swing analytics dashboard for the local Datacenter workspace. It displays file, storage, category, and system-usage information and refreshes its scan in the background.

## Requirements

- Java Development Kit
- Graphical desktop session
- A Datacenter folder at `~/Data`

## Build and run

```bash
unzip app-5.zip
javac -d build 5/App1.java
java -cp build App1
```
