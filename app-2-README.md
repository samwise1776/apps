# App 2 — Raylib Game

Archive: [`app-2.zip`](app-2.zip)

App 2 is a C#/.NET Raylib demo that opens an 800 × 600 window and renders a three-dimensional cube. The archive includes its project file and existing build output.

## Requirements

- .NET 10 SDK
- Graphical desktop session
- Raylib-cs 8.0.0, restored automatically by .NET

## Build and run

```bash
unzip app-2.zip
dotnet restore 2/apps.csproj
dotnet run --project 2/apps.csproj
```
