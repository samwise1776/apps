# Datacenter Apps

Individually packaged applications from the Datacenter project.

| App | Archive | Description | Technology |
|---|---|---|---|
| 1 | [`app-1.zip`](app-1.zip) | Datacenter app launcher, repair console, inspector, and log viewer | Java Swing |
| 2 | [`app-2.zip`](app-2.zip) | Raylib 3D cube game/demo | C#, .NET 10, Raylib-cs |
| 3 | [`app-3.zip`](app-3.zip) | Minimal Java game placeholder | Java |
| 4 | [`app-4.zip`](app-4.zip) | DataDocs desktop text editor | Java Swing |
| 5 | [`app-5.zip`](app-5.zip) | Datapro workspace analytics dashboard | Java Swing |

Each ZIP is a snapshot of its corresponding numbered directory under `/home/ray/Data/apps`.

## Requirements

- Java apps: a current JDK; the source project currently uses OpenJDK 26.
- C# app: .NET 10 SDK and a graphical desktop session.
- Graphical applications require a working Linux, Windows, or macOS desktop environment.

See each app's README for more details.
