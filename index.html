Get started

Download. Extract. Build.

The current downloads are source packages, giving you a transparent look at exactly what you run.

01

Choose an app

Download AppCenter for the easiest experience, or choose an individual source package from the catalog.

02

Extract the files

Unzip the package into a new folder. Keep the included directory structure intact before building.

03

Build and run

Open AppCenter and choose Install. It downloads, verifies, and prepares the selected app without a terminal.

Requirements

Desktop software, built from source.

  • AppCenter: Linux x64; Java is bundled and installed inside the app
  • DataDocs, Learner, ProjectHub: Java 17+ on Linux, Windows, or macOS
  • Trestrio: Node.js 18+ with npm; Electron is restored with npm ci
  • Velice: Python 3.10+; install it or run directly from the source package
  • Vexa: Java 17+; compile the interpreter before running an example
  • Verification: SHA-256 checksums are available in the GitHub repository
