If you want to make a website like this first you will need a index.html. Create the file called e.g index.html. you will have to write the following:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta viewport="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>

</body>
</html>

Make the <title>Document</title> be whatever website title you want.
